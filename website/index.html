About

I'm a software engineer and open-source builder. I create tools that push the boundaries of what developer tooling can be — combining modern AI with deep systems thinking.

My main project is Nova, an open-source terminal AI coding assistant built on LangGraph and the deepagents framework. It's a full-featured agentic coding tool with a Textual TUI, 25+ built-in tools, autonomous learning, MCP support, sandbox execution, and a plugin system — all running in your terminal.

I work across Python and TypeScript, building everything from CLI frameworks to penetration testing agents. I care deeply about architecture, clean design, and tools that respect the developer's craft.
