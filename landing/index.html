What makes Nova different

Sandboxed & Safe

Every AI action runs in an isolated Docker or E2B sandbox. Your system stays protected — no accidental file deletion, no rogue processes.

Connect Anywhere

Run Nova from Discord or Telegram. Start a session on your desktop, pick it up from your phone — the remote bridge keeps you in control.

Deep Agent Architecture

Built on LangGraph and deepagents. Nova spawns subagents for complex tasks — research, coding, testing — each with isolated context.

MCP Tool Integration

Connect any MCP-compatible server — databases, APIs, file systems. Nova discovers and wires them automatically at startup.

Session Persistence

Save and restore full conversations with LangGraph checkpoints. Switch models mid-session, resume exactly where you left off.

Open Source

MIT-licensed and built in the open. No vendor lock-in, no proprietary agents — just Python, LangChain, and your terminal.

How it works

→ → → →

Input

You type a command, ask a question, or give a task — just like a regular terminal. Nova parses it through a LangGraph agent graph that understands intent, extracts context from your project, and plans the execution.

$ nova → "scan this codebase"
ℹ Processing via LangGraph agent graph...

Agent

The core agent orchestrates the work. It can spawn subagents for research, coding, testing — each with isolated context. Built on the deepagents framework, it manages planning, tool selection, and multi-step reasoning automatically.

Agent: planning task "scan codebase"
→ spawning research subagent
→ spawning analysis subagent

Tools

Nova connects to MCP servers for databases, APIs, file systems, and web search. It also uses built-in tools for code editing, file operations, sandbox commands, and project graph queries — all routed through the agent.

🔧 12 tool calls · read_file×4, grep×3, shell×2, task

Sandbox

Every code execution, file operation, and shell command runs in an isolated sandbox — Docker, E2B, or remote. Your project files are mounted read-only; the sandbox gets its own workspace. No accidental damage to your system.

[ℹ] Sandbox ready — workspace: /tmp/nova-sandbox-abc123
[ℹ] Project mounted at /workspace (read-only)

Output

Results stream back to your terminal in real-time — code diffs, scan reports, test results. Nova can also push output to Discord or Telegram via the remote bridge, so you never miss a result.
